# 目的定義の失敗パターン集

レビュー中に検出した問題がここのパターンに一致したら、指摘にパターン名を添える。各パターンは「症状 → なぜ問題か → 検出方法 → 例」の順。例は書き方の型を示すためのフィクションであり、実レビューでは文書内の情報だけで修正案を作ること。

**検出の正式な判定手順(手段動詞リスト・抽象語リスト・3問バッテリー・判定表)は SKILL.md 側にある。本ファイルは症状の理解・パターン名の付与・修正例の型の参照に使う。両者が食い違って見える場合は SKILL.md を優先する。**

## 1. 手段の目的化
- 症状: 目的欄に「〜を導入する」「〜を実装する」「〜へ移行する」が置かれている。
- なぜ問題か: 手段は差し替え可能。目的が手段で書かれていると、より良い代替手段の検討も、達成判定もできなくなる。読み手は「導入して、それで?」で止まる。
- 検出: 目的文に「それは何のため?」と問うて上位の答えが出る。目的文の述語が導入・実装・移行・構築などの動作。
- 悪い例: 「目的: 認証設定をTerraformでIaC化する」
- 修正例: 「目的: 環境間の設定差分に起因する認証障害を再発ゼロにする(手段としてIaC化を採用)」

## 2. 抽象語シェルター
- 症状: 「効率化」「最適化」「強化」「推進」「高度化」だけで中身がない。
- なぜ問題か: 誰の・何が・どう変わるかが無いので、読み手ごとに違う絵を想像する。合意したつもりで合意できていない状態を作る。
- 検出: 抽象語に「具体的には誰の何がどうなる?」と問うて、文書内に答えがない。
- 悪い例: 「運用の効率化を目的とする」
- 修正例: 「月次のアカウント棚卸し作業(現状: 担当2名×3時間)の手作業をゼロにする」

## 3. 便益の主語欠落
- 症状: 「工数が削減される」「品質が向上する」— 誰にとってかが無い。
- なぜ問題か: 主語のない便益は検証できず、読み手(特に承認者)は自分に関係する話か判断できない。
- 検出: 便益文に主語を問う。「誰の工数?」「何の品質?」「どれだけ?」
- 悪い例: 「これにより工数が削減される」
- 修正例: 「サポートチームのパスワードリセット対応(週約20件)が自動化され、対応工数が週5時間減る」

## 4. 貢献チェーンの飛躍
- 症状: 「これをやれば売上/満足度に貢献する」— 中間の因果が書かれていない。
- なぜ問題か: 飛躍した因果は読み手に「本当に?」を発生させ、文書全体の信頼を下げる。投資判断の文書では致命的。
- 検出: 施策→事業効果の間を1段ずつ埋めようとして埋まらない。
- 悪い例: 「ログ基盤を整備することで売上に貢献する」
- 修正例: 「ログ基盤整備 → 障害の原因特定が平均4時間→30分 → 復旧が早まりSLA違反が減る → 解約理由の上位『障害対応の遅さ』を解消(仮定: 解約理由調査に基づく)」

## 5. 検証不能ゴール
- 症状: 「使いやすくする」「わかりやすくする」「安定させる」— 達成判定の基準がない。
- なぜ問題か: 終わりが定義されていない仕事は終わらないか、勝手に終わったことにされる。
- 検出: 「第三者がこの文だけを見て達成/未達成を判定できるか?」
- 悪い例: 「ログイン体験を使いやすくする」
- 修正例: 「ログイン完了までの平均タップ数を5→2にする」「ログイン起因の問い合わせを月30件→10件未満にする」

## 6. 目的のてんこ盛り
- 症状: 目的が3つ以上並列され、優先順位がない。
- なぜ問題か: トレードオフ発生時(工数・スコープの削減判断)に基準が無くなる。読み手は「本当は何がしたいのか」を推測させられる。
- 検出: 目的の列挙数と、主従・優先の明示の有無。
- 修正の型: 主目的を1つに絞り、残りは「副次的効果」または「非目的(今回は狙わない)」に振り分ける。

## 7. 課題なきWhy
- 症状: 背景に課題・痛みが書かれておらず、「やりたいから」「流行っているから」に見える。
- なぜ問題か: 読み手が「今のままで何が困るのか」を理解できないと、優先度をつけられない。
- 検出: 背景セクションに「放置した場合のコスト・リスク・機会損失」が1つも無い。
- 修正の型: 現状の事実 → それによる問題(頻度・影響範囲・金額/時間) → 放置した場合どうなるか、の3点を足す。

## 8. Why now の欠落
- 症状: なぜ「今」やるのかが書かれていない。承認・稟議系の文書で特に致命的。
- なぜ問題か: 承認者の実際の判断は「やるか/やらないか」より「今やるか/後でやるか」であることが多い。今やる理由が無い提案は「良い話だね、また今度」で終わる。
- 検出: 期限・締切・悪化トレンド・外部イベント(監査、法令、契約更新)への言及の有無。
- 修正の型: 「◯月に△があるため、それまでに」「問い合わせが四半期ごとに1.4倍で増えており」など、今やる根拠を1文入れる。
