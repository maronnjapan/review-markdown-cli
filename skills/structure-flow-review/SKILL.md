# 構成・流れレビュー

## このスキルで見ること

原稿の並び順と接続だけを見る。表現の巧拙や用語の正確さは見ない。
基準は「読み手が、いま何の話を読んでいるか分かるか」。

## 判断の順序

1. **結論の位置**
   節ごとに、その節の結論・要点が先に来ているか。
   前置きが長く、結論が末尾にある節を挙げる。

2. **見出しと中身の一致**
   見出しが約束した内容を、その配下が書いているか。
   見出しから予想できない話題が入っている箇所、見出しが内容より広い・狭い箇所を挙げる。

3. **段落のつながり**
   前の段落から次の段落への飛躍を挙げる。
   「なぜ急にこの話になったか」が読み取れない箇所が対象。

4. **話題の重複**
   同じ内容を複数箇所で説明している箇所を挙げ、どこへ寄せるかを書く。

5. **欠けている橋渡し**
   抽象的な主張と具体的な手順の間に、つなぎの説明が無い箇所を挙げる。
   逆に、具体例だけが並んで結局何が言いたいか示されない箇所も挙げる。

6. **並び替えの提案**
   節の順序を変えると読み手の理解が早くなる場合、どの節をどこへ動かすかを1つだけ提案する。

## 指摘の書き方

- 対象の箇所を1つ選び、そこに「この位置だと読み手はこう迷う」を書く。
- 移動・統合・分割のどれを提案しているかを明示する。
- 原稿全体の並びに関する指摘は、特定の箇所へ結び付けず、全体への指摘として書く。

## 重大度の目安

- must: 読み手が前提を持たないまま次へ進まされ、理解が崩れる。
- should: 読み直しや行きつ戻りつが必要になる。
- idea: 今のままでも読めるが、順序を変えると速く伝わる。
